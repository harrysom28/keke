hooks/usePlaceSearch.ts — key lines TS 
// Token generated on focus — one per search
const onFocus = useCallback(() => {
  if (!sessionToken.current) {
    sessionToken.current = uuidv4();
  }
}, []);

// Debounced search — 350ms wait
debounceTimer.current = setTimeout(async () => {
  await api.get('/places/search', {
    params: {
      q:            text.trim(),
      sessionToken: sessionToken.current, // ← same token
    }
  });
}, 350);

// Selection CLOSES the session
const onSelect = async (place) => {
  await api.get('/places/details', {
    params: {
      placeId:      place.placeId,
      sessionToken: sessionToken.current, // ← closes session
    }
  });

  // Reset — CRITICAL. Reusing a token breaks the session.
  sessionToken.current = null;
};
What breaks this: Reusing the same session token across two different search sessions. Google will then bill each individual autocomplete call at $2.83/1k instead of $17/1k sessions — a 6× cost increase. The sessionToken.current = null line after selection is mandatory.
04 — Cost Engineering Rules

The 6 Rules That Keep You Free

Every rule implemented in the provided code. Breaking any one of them can 5–10× your bill overnight.

Rule 01
Session Tokens — Always
Every autocomplete call carries a session token. The entire search (all keystrokes + Place Details) bills as one $0.017 session. Without this, each keystroke costs $2.83/1k.
6× cost reduction
Rule 02
Local Places First
PostGIS searches your seeded places database before calling Google. ~70% of searches in your city resolve locally (EBSU, Kpirikpiri Market, etc). These never touch Google.
~70% fewer Google calls
Rule 03
350ms Debounce + Min 2 Chars
User types "EBSU Parm Site" = 14 characters. Without debounce: 14 API calls. With 350ms debounce and 2-char minimum: 3–4 API calls per session. Still $0.017 total.
70% fewer calls per session
Rule 04
Directions Only on Confirmation
Pre-booking fare estimate uses free Haversine math (×1.4 road factor). Google Directions API is called only after the rider confirms. A cancellation costs $0 in routing.
Eliminates speculative calls
Rule 05
Aggressive Redis Caching
Place Details cached 30 days. Routes cached 24h by snapped coordinates. Geocodes cached 7 days. A popular EBSU→Market route is fetched once, then free for 24h regardless of how many riders take it.
60–80% cache hit rate
Rule 06
Field Masks on Place Details
Only request place_id, name, geometry/location, formatted_address. Requesting reviews, photos, opening_hours triggers Google's expensive tier. Only pay for what your UI shows.
Stays in cheapest billing tier

// Entire match decision: ~5ms, zero Google calls
export async function dispatchRide(rideId, rider, destination) {
  // 1. Zone lookup — which 500m cell is the rider in?
  const riderZone = locToZoneIndex(rider.location);         // ~0.1ms
  const surroundingZones = getSurroundingZones(riderZone);   // pure math

  // 2. Redis GEO — all drivers within 2km across 9 zones
  const nearbyDrivers = await queryZones(surroundingZones, rider.location); // ~2ms

  // 3. Rank by pre-computed travel time matrix (built at 2AM)
  const ranked = await rankByETA(nearbyDrivers, rider.location); // ~3ms Redis lookup

  // 4. Offer to best driver — total time so far: ~5ms, cost: $0.00
  const bestDriver = ranked[0];
  socket.to(bestDriver.driverId).emit('ride:offer', { rideId, rider, destination });

  return { driverId: bestDriver.driverId, etaSeconds: bestDriver.etaSeconds };
}

// Google Directions called HERE — once, after driver acceptance
export async function onDriverAccepts(rideId, driverLocation) {
  const [pickupRoute, tripRoute] = await Promise.all([
    getDirections(driverLocation, pending.origin),      // $0.005 (cached 24h)
    getDirections(pending.origin, pending.destination),  // $0.005 (cached 24h)
  ]);
  return { pickupRoute, tripRoute };
}
